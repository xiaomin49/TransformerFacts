# Oracle（ORCL）财报特化配置

本文件为 `sec-earnings-analysis` 技能的 ticker 特化补充。分析 ORCL 前先读本文件，获取财年映射、特有指标清单与易错点，避免把通用 SaaS 模板套到 Oracle 上。

## 财年与日历映射

- 财年截止日：**每年 5 月 31 日**。
- 命名规则：以**财年截止日所在日历年**命名（与 Oracle 官方一致）。即 Fiscal 2027 = 截至 2026-05-31 的 12 个月；Fiscal 2028 = 截至 2027-05-31。
- 季度划分示例：Q1 FY2027 = 2025-06-01 ~ 2026-08-31（截止 2026-08-31）；Q4 FY2026 = 截至 2026-05-31；Q1 FY2026 = 截至 2025-08-31。
- 注意：季度截止日（如 2026-08-31）早于公告日（如 2026-09-10）约 1–2 周，报告文首务必同时写「截止日」与「公告日」。

## 特有指标清单（Step 3 逐项核对）

- 云基础设施（IaaS / OCI）收入与增速：当前核心增长引擎，常呈三位数增长，需单独成项并算其在总收入中的 mix 占比变化。
- 云应用（SaaS）收入与增速：Fusion（ERP/行业应用）、NetSuite（中小企业 ERP）、行业应用；通常个位数~双位数增长，明显慢于 IaaS。
- 总云收入（IaaS + SaaS）与 mix：通常已占总收入 55%~60%+，是判断「上云迁移」进度的主指标。
- RPO（剩余履约义务）：规模、YoY、QoQ、本季新增 AI 云合同额；管理层口径「约一半 RPO 在 36 个月内转化为收入」。
- 传统软件（许可 License 通常同比 -15% 量级、本地支持 Support 微降）：结构性下行，对总收入拖累约 3 个百分点，属「客户迁移上云」必然结果，需在报告中点明而非当作经营失误。
- 硬件（含 engineered systems）与服务。
- CapEx 与「净现金 CapEx」：Oracle 8-K 会同时披露总 CapEx 与剔除「客户重大融资成分预付 / 短期融资」后的净现金 CapEx，二者差异巨大，必须同时列出。
- 自由现金流（OCF − CapEx）：当前为大额负值，是「为抢 AI 云产能主动投入」的阶段性结果，不是经营恶化。
- 毛利率：受数据中心爬坡 + 低毛利基础设施收入占比上升拖累，常承压下滑；管理层视其为需重点关注的指标（CFO 称经营利润率为「北极星」）。
- 经营利润率（Non-GAAP 北极星指标）。
- 多云端（OCI on Azure / Google Cloud / Microsoft 数据库互操作）：Oracle 差异化增长驱动，8-K 或纪要常提。
- Cerner / 医疗应用、Fusion Agentic AI：应用层 AI 进展。

## 易错点 / 反误导

- **Ampere 一次性收益扭曲 EPS 同比**：Q2 FY26 含出售 Ampere 权益的一次性投资收益。因此 Q2 FY27 的 Non-GAAP EPS 同比若「含」该收益则为负（约 -14%~-19%），「剔除」后为正（约 +19%~+25%）。写指引与同比时必须显式区分「含/不含」一次性项，否则读者会被 -19% 误导。
- **CapEx ≠ 现金支出**：AI 大单多采用「自带硬件（BYO hardware）/ 供应商融资（客户付款后 Oracle 再向供应商付容量款）/ 客户预付」结构，不要求 Oracle 先垫现金。因而「净现金 CapEx」远小于报表总 CapEx，且这些收入与 CapEx 影响多递延到 FY28 及以后。
- **FCF 转正时点未给**：管理层仅定性「FY27/FY28 为 CapEx 峰值年，之后改善」，未给具体季度；报告中标 `[待管理层明确]`，不得臆测。
- **RPO 当前/非当前明细、地理拆分、并购主体**：通常待 10-Q 披露，标 `[待 10-Q]`。

## 数据来源技巧

- 当季 8-K 附件 99.1 的新闻稿与随附财务报表含「本季 / 上季 / 上年同期」三列对比表，QoQ 与 YoY 均可从同一份文件取，优先用此表。
- 上季绝对数亦可从 8-K 补充分析表或上一份 10-Q 取；本数据集暂无 Q4 FY26 的 10-Q 时，以当季 8-K 对比表为准。
- 文件命名模式：`ORCL_8-K_{YYYY-MM-DD}_orcl-ex99_1.htm`（业绩公告）、`ORCL_10-Q_{YYYY-MM-DD}_orcl-{period}.htm`、`ORCL_10-K_*.htm`、电话会 `Oracle Corporation_{YYYY-MM-DD}_transcript.pdf`。
