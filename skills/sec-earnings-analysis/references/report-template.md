# 财报解读报告模板（纯文本版）

本模板是 `sec-earnings-analysis` 技能的成稿结构。硬性约束见 SKILL.md：全文禁止 Markdown 表格与二级/嵌套列表，只使用一级列表与短段落；只引用本地 SEC 文件；不引用媒体/外部一致预期。

## 文件命名与位置

- 文件名：`{TICKER}_FY{年度}Q{n}_财报解读_{YYYY-MM-DD}.md`
- 位置：该公司财报目录，如 `~/data/sec_filings/SNOW/`，示例：`SNOW_FY2027Q2_财报解读_2026-09-02.md`

## 文首头部（报告元信息）

使用纯文本行（非表格）声明，随后用一级列表逐条列出：
- 报告期与截止日、发布日期（例如：FY2027 Q2，季度截止 2026-07-31，2026-09-02 盘后发布）
- 数据来源（仅列本地 SEC 文件全名，多份文件时每条占一行）
- 财年/币种/口径说明（例如：财年截至每年 1 月 31 日；美元；GAAP 与 Non-GAAP 双口径）
- 免责声明：本报告仅供研究参考，不构成投资建议。

数据来源的具体写法（全部顶格 `- `，不缩进）：
- `{TICKER}_8-K_{日期}_...htm`（附件 99.1 新闻稿，当季）
- `{TICKER}_10-Q_{日期}_...htm`（上一季度，用于环比）

## 报告主体（六段式）

### 1. 财报快照

- 一句话业绩：先给结论型概括（例如“产品收入连续第三季加速、利润率改善、指引上调”）。
- 核心财务数据，每条数据自成一个列表项，项内含本期 / 同比上年同期 / 环比上季三组信息（用括号和分号写全）：总收入与分业务收入（如 SaaS 公司：产品收入、专业服务及其他）、GAAP 毛利润与毛利率、GAAP 营业利润与利润率、GAAP 净利润与摊薄 EPS、Non-GAAP 营业利润与利润率、Non-GAAP 净利润、Non-GAAP 摊薄 EPS、经营现金流、自由现金流、调整后自由现金流（如有）。
- 关键经营指标（公司特有）：如 NRR（净收入留存率）、TTM >$100 万客户数、Forbes Global 2000 客户数、RPO、净新增客户。数据来源统一在条目后或小节末尾标注（如“来源：8-K 新闻稿 / Q1 FY27 10-Q”）。
- Oracle（ORCL）特有指标见 `references/ticker-oracle.md`：OCI(IaaS)/SaaS 拆分与 mix、RPO 规模与转化节奏、CapEx 与净现金 CapEx 区分、Ampere 一次性收益对 EPS 同比的扭曲、传统软件许可/支持的结构性下行、多云端（OCI on Azure/Google Cloud）。
- 注明：不做媒体一致预期对比（除非用户另行授权）；若确有对比需求，标注需用户提供数据。

### 2. 经营要点与驱动

- 增长驱动拆解（逐条列出）：增速趋势（如“连续第 N 季度加速”）及其含义、AI/新产品对财务贡献的证据（使用量指标、客户案例点名、产品能力上线数）、客户增长质量（净新增客户结构、大客户渗透）、利润率改善来源（运营杠杆/费用率变化）。每条给数据或原文依据。
- 区域/分线结构：本地文件披露了什么写什么；8-K 未披露的注明“待 10-Q”。
- 小结：本期由哪些“量 / 价 / 结构 / 外部因素”主导 + 一句话总结。

### 3. 指引

- 下一季度指引：区间/中值与隐含 YoY。
- 全年指引：上修/维持/下修，给出前值与变化幅度。
- 解读：指引隐含的下半年增速是否自洽、管理层对持续性的判断。
- 说明：无媒体一致预期对比；若需对比，请用户提供一致预期数据。

### 4. 管理层重要谈话

- 只摘录本地文件中的原话（8-K 新闻稿 CEO/CFO 引言；若本地有电话会纪要 PDF 则补充，注明来源）。
- 积极信号与逻辑。
- 需关注信号 / 风险点（如现金流弱、RPO 环比回落、GAAP 仍亏损、SBC 占比、竞争与定价风险），每条给数据或原文依据。

### 5. 财务健康度

- 资产负债与杠杆（逐条列出）：现金及等价物、短期投资、长期投资、现金+投资合计、可转债/有息负债、净现金、股东权益。
- 判断：净现金/净负债状态、到期结构、流动性。
- CapEx 与资本配置：购建固定资产金额（体现轻重资产模式）、回购、并购（商誉变化）。
- 资本回报方向：ROE/ROIC 趋势（GAAP 亏损则说明方向性与限制）。
- 小结：短中期财务韧性与潜在约束。

### 附：证据核验与不确定性说明

- 一致性声明：所有数字均来自哪些本地文件（列出文件名）。
- 待确认项：逐条列出（如 Q2 地理拆分待 10-Q、电话会问答待纪要文本、某些数字为推算近似值）。
- 口径说明：Non-GAAP 剔除项定义；YoY/QoQ 对齐对象。
- 角色边界声明：只摆证据与逻辑，无买卖建议/目标价/确定性结论。

## 交付前自查清单

1. 全文无 Markdown 表格与复杂格式（用 Grep 查 `\|`）
2. 全文无二级/嵌套列表（所有列表项顶格，无缩进子项；用 Grep 查 `^[[:space:]]+- ` 之类的缩进行首）
3. 无任何媒体/外部来源引用（公司公告文件名除外）
4. 每个关键数字都有本地来源或标注缺口
5. 中文、口径统一（币种/单位/财年/GAAP-Non-GAAP）
6. 不含买卖建议/目标价/确定性结论；含免责声明
7. 文件名与位置符合命名规范
8. 报告在 present_files 中展示，临时文件已清理
