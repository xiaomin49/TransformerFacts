🔧 开源生态焦点：Agent Harness 双雄 — OpenAI Codex Harness vs DeepSeek Harness

🔍 关键解读

  1. 增速反差：DeepSeek Harness 仅用约 14 天冲到 215,759 Star，已反超 Codex 的 122,417。但需注意 Codex 仓库更早（2025-04 的 Codex CLI），Harness 内核是 08-19 才完全开源——若只看开源后增量，DeepSeek 的 Star 增速（约 14k/日）显著领先，反映「MIT + 全插件化」对社区心智的强吸引力。
  2. 哲学分野：OpenAI 把 Harness 当作平台层——开发者保留自有 UI，app-server 负责 Agent Loop、沙箱与审批；DeepSeek 走元框架路线，用 Cordis 把一切抽象为可重组插件，并强调自托管与省 Token。前者抢企业嵌入，后者抢开发者自由度。
  3. 模型层互通：Codex Harness 明确支持切换到 DeepSeek 等任意 OpenAI 兼容端点。两大生态在模型层互通，真正竞争集中在执行层、工具编排与可观测性。
  4. 「Harness > 模型」的实证：OpenAI 披露 ARC-AGI-3 上，同一模型 GPT-5.6 Sol 仅靠 Harness 优化（保留推理轨迹 + 上下文压缩）得分 13.3% → 38.3%，输出 token 降 6 倍——证明执行框架对效果的影响可超过一次模型升级。
  5. 战略含义：模型实验室的竞争从「参数 / 权重 / 价格」延伸到「Agent 运行时」。DeepSeek 借 MIT 抢社区，OpenAI 借 Apache-2.0 + 生产级 Rust 内核抢企业；两者都把模型封装进可控、可审批、可持久化的 Harness，验证了行业从「卖模型」到「卖运行时」的范式迁移。
