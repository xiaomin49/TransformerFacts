🗺️ OpenRouter 数据分析

OpenRouter 作为多模型路由聚合平台，其调用量分布能直观反映中国模型与开源模型在全球开发者中的实际渗透率变化。本周中国模型份额 73.8%（上升），开源模型份额 56.6%（上升）。 中国模型份额从年初的 24.3% 暴增至本周的 73.8%，但增速曲线呈现"M 型"——3 月下旬曾触及 74% 峰值后回落，直到 6 月下旬才重新加速——增长逻辑正从"价格驱动"切换到"质量驱动"。开源模型份额的波动性（标准差约 12%）远大于中国模型，高度依赖头部开源模型（DeepSeek、Meta）的发布事件，而非持续性的社区使用。中国模型与开源模型份额的差值（17.3pp）反映中国模型中的闭源 API 付费占比，本周差值创近 6 周新高，可能意味着 DeepSeek 付费 API 采用率和阿里 Qwen-Max API 调用在同步加速。
口径说明：「开源占比」按开源权重厂商集（DeepSeek / Meta / Mistral / Alibaba / Nousresearch / Arcee-Ai / Tngtech）及 model_id 含 :free 的模型加总估算，属厂商维度的近似口径，并非逐模型的开源权重判定；且个别周存在同模型多版本快照重复计入，导致份额分母偏大，数值略被低估。趋势方向仍具参考意义。

🔬 Vercel AI Gateway 实验室份额（OpenAI / Anthropic / Google）

Vercel AI Gateway 是 Next.js 生态的原生 AI 路由层，其实验室（lab）调用分布反映前沿开发者的模型选择。支出占比：Anthropic 36.3%、OpenAI 8.9%、Google 5.4%。Token 占比：Anthropic 10.9%、OpenAI 7.4%、Google 1.9%。Anthropic 以最高单价模型占据支出榜首，但在 Token 量方面优势收窄——这说明 Anthropic 的调用者偏向高价值、低频率的复杂任务（如代码生成、长链推理），而低价模型（如 DeepSeek）主导了高频批量任务。该数据每周采集一次。

11 月 Anthropic 支出占比为何扩大？11 月以来其支出占比均值 39.8%，较 10 月均值 34.7% 抬升 +5.1pp（单日峰值 54.5%），而同期 Token 份额基本持平（11.9% → 11.7%）——支出增量几乎全部来自「模型结构上移」而非用量扩张：① Claude Opus 5.5（$4/$20 每 M tokens）持续爬坡承接 Agentic 编码任务，Anthropic 隐含单价倍数（spend% ÷ token%）达 3.4，为三大实验室最高（OpenAI 1.5、Google 3.0）；② 竞争格局变化：11 月智谱系（z.ai）支出份额自 ~19% 回落至 ~10%、Google 亦回落 2.2pp，释放的预算向 Anthropic 集中；③ 需求端印证：Claude Code 本周 NPM 下载 +10.0% 至 14.2M，Anthropic Q3 营收 $16.8B（环比 +46%）显示企业侧 API 消费放量，OpenRouter 侧 Anthropic 周处理量 10 月亦从 11.7T 爬升至 16.1T，与 Vercel 口径互为印证。提示：份额为相对量——其他实验室份额回落同样会放大 Anthropic 的占比读数；若 Opus 5.5 爬坡放缓或低价模型流量回补，支出占比可能回落。

🔥 硅基通胀

GPU 租赁价格（vast.ai 聚合口径）自 2025-10-23 的 $1.90/hr 升至 2026-11-12 的 $3.28/hr，累计 +72.6%，周环比 +10.6%；MA30 平滑值 $3.25/hr，趋势斜率仍未走平。
把两条价格曲线并排看，结论就出来了：算力租金在涨（硅基通胀），Token 售价在跌（智能通缩）。GPU $1.90 → $3.28/hr（+72.6%）对 OPTI Vercel Output $9.23 → $4.25/M tokens（-54.0%）。单位智能的「原料」涨价而「成品」降价，价格剪刀差即为推理侧的毛利压缩幅度；行业成本优势持续向自有算力、自研芯片与高利用率集群的厂商集中，纯转售算力的中间层被两头挤压，这是未来 2~4 个季度判断 AI 基建估值的关键变量。
