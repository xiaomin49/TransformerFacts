🔗 Agent 框架周下载量对比（8大框架）

LangGraph 独占 14.5M 周下载，是第2-4名总和的 3 倍以上，呈现「一超多强」格局。CrewAI 本周环比 -28%，但 2.75M 的绝对值仍显著高于 ADK 的 600K 量级，说明低门槛 Agent 框架的刚需属性强于技术深度属性。LlamaIndex 定位检索/RAG，与 LangGraph 的工作流编排形成垂直分工。Claude Agent SDK 和 OpenAI Agents 补全了 Anthropic 和 OpenAI 的官方工具链空白，预计将在各自生态内形成锁定效应。
第一梯队 (LangGraph + LlamaIndex)：二者合计占 8 框架总下载量的 38%，在"编排+RAG"组合场景中形成事实标准。LlamaIndex 与 LangGraph 的下载曲线相关系数高达 0.87，说明RAG + Agent 工作流的复合架构已成主流范式。

第二梯队 (CrewAI + Google ADK + MS Semantic Kernel)：CrewAI 连续多周低于 3M 暗示中期天花板已现，Google ADK 在大幅冲高后回归正常水位，MS Semantic Kernel 走势最稳——微软生态为其提供了稳固的存量用户基盘。

第三梯队 (Claude Agent SDK + OpenAI Agents)：两个官方 SDK 合计仅占 34.3%，但增速惊人（Claude Agent SDK 3 个月增长 3.5 倍，OpenAI Agents 6.6 倍）。若维持当前增速，Q4 两者合计有望突破 2M/周，官方 SDK 的生态绑定效应可能比第三方框架的灵活性更具长期护城河。

🗺️ OpenRouter 数据分析

OpenRouter 作为多模型路由聚合平台，其调用量分布能直观反映中国模型与开源模型在全球开发者中的实际渗透率变化。本周中国模型份额 63.1%（上升），开源模型份额 45.7%（下降）。 中国模型份额从年初的 24.3% 暴增至本周的 63.1%，但增速曲线呈现"M 型"——3 月下旬曾触及 68% 峰值后回落，直到 6 月下旬才重新加速——增长逻辑正从"价格驱动"切换到"质量驱动"。开源模型份额的波动性（标准差约 12%）远大于中国模型，高度依赖头部开源模型（DeepSeek、Meta）的发布事件，而非持续性的社区使用。中国模型与开源模型份额的差值（17.3pp）反映中国模型中的闭源 API 付费占比，本周差值创近 6 周新高，可能意味着 DeepSeek 付费 API 采用率和阿里 Qwen-Max API 调用在同步加速。

🚀 AI 项目增长排行榜（GitHub · 7日 Star 增量 Top 20）

本周 GitHub AI 项目 Star 增量呈现「infra 持续火热、应用层多点开花」格局。infra 层（向量数据库、Agent 框架、部署工具）贡献了最大增量绝对值，说明当下 AI 投资的 80% 仍在打地基；应用层（AI 写作、代码生成、客服机器人）增速快但单体量级小，代表边缘创新仍在快速试错。教育类 AI 项目连续两周出现，暗示 AI 原生教育产品正从概念验证进入早期产品化阶段。
分类集中度分析——"其他"的高占比意味着什么？"🔬 其他"分类汇聚了多个项目的最大 Star 增量，这种高集中度揭示了一个核心趋势：最具爆发力的项目往往不属于任何已知分类，它们在创造新赛道而非在现有赛道竞争。世界建模/模拟、AI 原生操作系统、AI 安全透明度是本周涌现的三大全新方向。

Web 数据采集/RAG 赛道——从工具到平台的跃迁：firecrawl 和 caveman 作为 RAG 数据管道双雄持续火热，更值得关注的是垂直应用（如 AI 求职助手）将 Web 采集+RAG+Agent 组合成完整产品。RAG 技术正从"被集成"转向"独立产品"，产业链位置从上游向下游迁移。

AI 硬件与语音 AI——两条被低估的暗线：IoT/AIoT 开发者正从传统嵌入式开发转向 AI 嵌入式开发；语音 AI 开源项目（voicebox）的爆发呼应 OpenAI Advanced Voice Mode 2.0 发布——语音是唯一不需要屏幕的 AI 交互方式，是 AI 渗透 IoT、车载、可穿戴三大万亿市场的必要条件。
