🗺️ OpenRouter 数据分析

OpenRouter 作为多模型路由聚合平台，其调用量分布能直观反映中国模型与开源模型在全球开发者中的实际渗透率变化。本周中国模型份额 70.7%（上升），开源模型份额 61.3%（上升）。 中国模型份额从年初的 24.3% 暴增至本周的 70.7%，但增速曲线呈现"M 型"——3 月下旬曾触及 71% 峰值后回落，直到 6 月下旬才重新加速——增长逻辑正从"价格驱动"切换到"质量驱动"。开源模型份额的波动性（标准差约 12%）远大于中国模型，高度依赖头部开源模型（DeepSeek、Meta）的发布事件，而非持续性的社区使用。中国模型与开源模型份额的差值（9.4pp）反映中国模型中的闭源 API 付费占比，本周差值创近 6 周新高，可能意味着 DeepSeek 付费 API 采用率和阿里 Qwen-Max API 调用在同步加速。
口径说明：「开源占比」按开源权重厂商集（DeepSeek / Meta / Mistral / Alibaba / Nousresearch / Arcee-Ai / Tngtech）及 model_id 含 :free 的模型加总估算，属厂商维度的近似口径，并非逐模型的开源权重判定；且个别周存在同模型多版本快照重复计入，导致份额分母偏大，数值略被低估。趋势方向仍具参考意义。

💰 Token 价格观察

OPTI Vercel Token 价格指数（按 Vercel AI Gateway 各模型 tokens 份额加权，剔除无价模型与 Other 桶后归一化）最新读数 2026-10-26：Input $0.5692/M tokens（周环比 -31.4%，自 2026-07-10 累计 -69.7%）· Output $2.4227/M tokens（周环比 -30.7%，累计 -73.7%）。
自 2026-07-10 至今，Input 累计 -69.7%、Output 累计 -73.7%，「每百万 token 的智能」正在快速贬值：一方面新一代低价高能模型持续替代旧旗舰成为流量主体，另一方面缓存复用与推理批处理把有效单价继续压低。Token 单价通缩对应用层是纯利好——同等预算可采购数倍推理量，Agent、长上下文与多轮工作流的经济性因此成立。
三周反弹归因：两大 Token 价格指数为何同步走高？ OPTI（Vercel，日频）自 9 月中旬低点（09-18，Input $0.45 / Output $2.02）回升至 10 月中旬峰值（10-15，$1.23 / $5.64，累计 +172% / +179%），10-26 回落至 $0.57 / $2.42；OTPI（OpenRouter，周频）三周内 Input +261.6%、Output +473.1%（2026-09-28 → 2026-10-19）。核心结论：这不是厂商涨价，而是流量结构切换。两大指数均为「按 token 份额加权的模型标价均值」，9 月指数被单一超低价模型深度锚定（Vercel 上 DeepSeek V4.1 Flash 一度占 tokens 68%），10 月这一垄断份额瓦解（回落至 15%~20%），流量向贵价模型再分布：Claude Opus 5.5（09-21 发布，$4/$20 每 M tokens）在 OpenRouter 有价 token 份额三周从 0 爬坡至 8.6%、在 Vercel 爬坡至 4%~9%，仅此一款对 OTPI Output 的贡献即 +$1.71/M，约占三周涨幅（+$2.21）的七成；GPT-6.1 Sol、Claude Sonnet 5.5、GLM 5.3（非 Flash 版）等中高价模型同步上量。此外 DeepSeek 新版 v4.1-flash-20261017 较旧版单价 +20%（$1.00 → $1.20/M），亦有边际推动。背后是 Agentic 编码与高价值任务放量——与本期「收入动态」中 Anthropic Q3 营收 $16.8B（环比 +46%）相互印证： premium 模型的 token 消耗正在跑赢大盘。需提示：份额加权均价对「结构」远比对「价格」敏感，若低价模型份额回补，指数将自然回落（Vercel 10 月下旬已现回落迹象），单周读数不宜外推为通胀趋势。

🔥 硅基通胀

GPU 租赁价格（vast.ai 聚合口径）自 2025-10-23 的 $1.90/hr 升至 2026-10-26 的 $3.51/hr，累计 +84.7%，周环比 +11.4%；MA30 平滑值 $3.15/hr，趋势斜率仍未走平。
把两条价格曲线并排看，结论就出来了：算力租金在涨（硅基通胀），Token 售价在跌（智能通缩）。GPU $1.90 → $3.51/hr（+84.7%）对 OPTI Vercel Output $9.23 → $2.42/M tokens（-73.7%）。单位智能的「原料」涨价而「成品」降价，价格剪刀差即为推理侧的毛利压缩幅度；行业成本优势持续向自有算力、自研芯片与高利用率集群的厂商集中，纯转售算力的中间层被两头挤压，这是未来 2~4 个季度判断 AI 基建估值的关键变量。
