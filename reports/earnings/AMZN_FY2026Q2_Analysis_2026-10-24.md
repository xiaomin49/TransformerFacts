### 与市场一致预期对比（公开报道共识，提取日期 2026-10-24）

- **净销售额**：实际 **$200.6B** vs 共识 **~$197.0B**（香港经济日报 引 ~$197.01B；证券时报 引 ~$197B）→ **超预期约 +1.8%**。
- **经营利润**：实际 **$27.5B** vs 共识 **~$23.6B**（香港经济日报 引 ~$236.1B）→ **超预期约 +16%**；经营利润率 13.7% vs 预期 ~12%。
- **AWS 营收**：实际 **$42.2B** vs 共识 **~$40.5B**（香港经济日报 引 ~$405.4B）→ **超预期约 +4.2%**；增速 36.7% vs 预期 ~31%。
- **股价反应**：盘后一度 **+9% 至 +10%**，次日收涨（证券时报报周五 +15.32%，香港经济日报报 +3.9% 全日 / 盘后 +9%）。全面 beat + capex 上修共同推动（[来源: 证券时报 / 香港经济日报, 2026-07-31]）。

> 结果：**销售、经营利润、AWS 三项全面 beat**，盘后大涨；但 FCF（TTM）转负与 2026 capex 上修至 ~$220B 是需关注的反向信号。实际财务数字以本地 SEC 文件为准。

## 二、经营要点与驱动

- **AWS 爆发 +37%**（$42.2B，年化运行率 ~$169B）：18 个季度以来最快增速，且连续第五季加速；经营利润率 **39.4%**（TTM 36.8%），在三大云厂中领先（[来源: 8-K / 证券时报, 2026-07-30]）。Andy Jassy：「AWS is booming, growing 36.7% year-over-year in Q2—our fastest growth in 18 quarters」。
- **AI 与自研芯片各自破 $25B 运行率**：AWS 的 AI 业务与自研芯片业务年化收入运行率**各自突破 $25B**，均录得三位数百分比增长（[来源: 8-K CEO 引言]）。
- **零售稳健**：北美 +16%、国际 +15%；Prime 会员半年度配送速度创纪录（同日/次日达商品量 +40%+），Grocery 与 Everyday Essentials 增速领先整体（[来源: 8-K]）。
- **广告 +26%**（$19,809M），受 Sponsored ads / 零售流量驱动（[来源: 8-K 分部]）。
- **Trainium / Graviton 动能**：Anthropic 与 OpenAI 均作出多年、多 GW 级的 Trainium 使用承诺；Graviton 用于 98% 的 top-1000 EC2 客户，承诺额环比近 3x（[来源: 8-K]）。
- **Bedrock 放量**：数十万客户，过去半年新增客户超推出后首两年总和；**Q2 单季客户在 Bedrock 的支出超过此前所有季度累计**（[来源: 8-K]）。

**小结**：本期增长由「AWS 加速 + AI/芯片运行率破 $25B + 零售效率提升」主导；AWS 贡献约 21% 营收但超 60% 经营利润，是估值核心引擎。

## 三、非财务 AI 指标（AMZN 专项）

> 本节取自 `wiki/concepts/non-financial-ai-metrics.md` 的 AMZN schema 与趋势（Q3'25→Q2'26）。AMZN 用自然年季度，非财务 AI 披露偏「运行率 / 客户数 / backlog」导向。

**AMZN 专属 metric schema（最新 Q2'26）**

| 指标 | 单位 | 最新（Q2'26，截至 2026-06-30） |
|---|---|---|
| Alexa for Shopping 活跃用户（12 个月） | 亿 | >3.5 使用过；活跃同比近翻倍（互动 +5x） |
| AWS AI 业务年化运行率 | $B | >25（三位数% YoY） |
| Chips 业务年化运行率 | $B | >25（三位数% YoY） |
| Bedrock 客户数 | 家 | 数十万（Q2 支出 > 此前所有季度之和） |
| AWS Backlog | $B | 496（三位数% YoY） |
| Kiro（编码 agent）用量 | Q/Q | 3x |
| Trainium / Graviton 采用 | — | Anthropic/OpenAI 多年多 GW；Graviton 前 1000 EC2 客户 98% |

**核心 4 季趋势（自然季 Q3'25→Q2'26）**

| 指标 | Q3'25 | Q4'25 | Q1'26 | Q2'26 |
|---|---|---|---|---|
| AWS 营收（$B） | 33.0 | 35.6 | 37.6 | 42.2 |
| AWS 营收同比 | +20.2% | +24% | +28% | +37% |
| AWS Backlog（$B） | 200 | 244 | 364 | 496 |

- AWS Backlog 全年 2.5 倍（200→496），与 AWS 收入增速同步加速；AI/Chips 运行率 Q1'26 $15B → Q2'26 >$25B。

**跨家可比性注脚**（来自概念页）：**AWS Backlog（$496B）** 是「Cloud backlog / RPO」可比核心项，可直接对齐 GOOG Cloud backlog（$514B）、ORCL RPO（$664B）、MSFT cRPO（$678B）；AMZN 量级第三、增速三位数%。AMZN 不披露第一方模型 API 吞吐量，其 AI 势能靠「运行率 + Bedrock 客户 + Backlog」表征，与 GOOG 的 token 口径不可直接比。

**小结**：AMZN 的 AI 势能呈现「运行率快速突破 + Backlog 三级跳 + 自研芯片绑定头部实验室」特征，且 AWS 利润率维持 39%+，是 hyperscaler 中 AI 变现最顺、利润质量最高的样本。

## 五、管理层重要谈话

**Andy Jassy（CEO）**
- "AWS is booming, growing 36.7% year-over-year in Q2—our fastest growth in 18 quarters—and our AI and Chips businesses each eclipsed run rates of more than $25 billion."（[来源: 8-K 引言]）
- 资本开支："even at this level, we won't have enough capacity to meet all demand in 2026, and I believe that trend continues in 2027."（[来源: 电话会, 证券时报转述, 2026-07-31]）
- 自研芯片：Trainium2 性价比已优于同类 GPU 约 30%，且基本售罄；OpenAI 与 Anthropic 作出多年、多 GW 级 Trainium 承诺（[来源: 8-K]）。
- Agent 生态：Bedrock AgentCore、AWS DevOps Agent、Kiro（iOS 上线、用量 3x QoQ）、Amazon Quick（agentic 工作伴侣）密集发布（[来源: 8-K]）。

**积极信号**：AWS 增速阶跃、利润率领先、AI/芯片运行率破 $25B、Backlog $496B 三位数增长、零售效率创新高。
**消极 / 需关注信号**：FCF（TTM）转负（−$7.6B），capex（TTM）+64% 至 $169B；长期债务半年翻倍至 $128.9B 以支撑 AI 基建；净利润含 $53.4B Anthropic 投资重估，表观 EPS 失真。

## 六、财务健康度

> 数据来源：AMZN 8-K（2026-07-30）/ 10-Q（2026-07-31）现金流量表、资产负债表。

| 指标 | 数值 | 备注 |
|---|---|---|
| OCF（TTM） | $161.4B | 同比 +33% |
| PP&E 采购（TTM） | $169.0B | 同比 +64% |
| **OCF / CapEx（TTM）** | **0.95x** | **首次跌破 1**，自由现金流转负 |
| FCF（TTM） | **−$7.6B** | 去年同期 +$18.2B |
| 现金 + 有价证券 | ~$123.0B | 现金 $78.2B + 有价证券 $44.8B |
| 长期债务 | $128.9B | 较年初 $65.6B 翻倍 |
| 融资现金流（TTM） | +$75.2B | 债务 + 股权融资补 capex 缺口 |
| 股东权益 | $551.6B | 较年初 +$140.6B（含权益重估） |

- **杠杆 / 流动性**：长期债务翻倍但仍以投资级为主；现金 + 有价证券 ~$123B 提供缓冲；融资现金流 TTM +$75.2B 显示正主动举债 / 股权融资支撑 capex。
- **CapEx 周期定位**：OCF/CapEx（TTM）**0.95x（首破 1）**，FCF 转负——与 META（Q3'26 FCF −$2.1B、OCF/CapEx 0.94x）、ORCL（结构性债务驱动）同处"AI capex 前置吞噬现金流"区间；但 AMZN 的 OCF 基数更大、AWS 利润率更高，现金转化能力强于 META/ORCL。
- **表外 / 合同承诺**：与 GOOG/META 类似，数据中心租约与云算力采购形成未来义务；本季未单列总额，待 10-Q 合同承诺披露。

**小结**：AMZN 短中期财务韧性来自「零售现金牛 + AWS 高利润 + 投资级融资能力」，但 **TTM FCF 已转负、OCF/CapEx 首破 1、长期债务翻倍** 三重合力，使 2026 年自由现金流转负概率高；相对有 Cloud/RPO 预收垫底的同业，AMZN 对 AWS 增速最敏感。
