## 二、经营要点与驱动

- **OCI 阶跃加速 +121%**（$4.1B→$7.4B QoQ +27.7%）：从 FY26Q4 +93% 跳升，需求侧供给约束型加速；公司交付 **850MW 数据中心容量**、季内交付 **>30 万颗 GPU**（约为 Q4 的 3 倍）（[来源: 8-K / onemoremoney, 2026-09]）。
- **云应用 SaaS +10%**、**软件 −3%**（客户持续从本地向云迁移），**多云数据库 +353%**（[来源: 8-K / 财报幻灯片]）。
- **RPO $664B（+$209B YoY）**：增量主要来自大型 AI 云合同，其中**客户预付款 / 自带硬件（BYO）模式占比高**，降低 ORCL 自身资本支出压力（[来源: 8-K / onemoremoney]）。
- **区域与行业**：OCI 在多云（Azure / AWS / GCP 互联）与行业应用（Fusion / NetSuite 嵌入 AI）双线扩张。

**小结**：本期增长由「OCI 阶跃 + RPO 暴增 + 多云数据库放量」主导，传统软件温和下滑；核心矛盾是"订单与收入在加速，但 capex 与 FCF 承压"。

> 本节取自 `wiki/concepts/non-financial-ai-metrics.md` 的 ORCL schema 与趋势（FY26Q2→FY27Q1）。ORCL 非财务 AI 指标披露极少，主要看**财务侧 AI 势能代理**（RPO / OCI 增速 / GPU 交付 / 容量）。

| 指标 | 单位 | 最新（FY27Q1） |
|---|---|---|
| OCI (IaaS) 营收同比 | % | +121%（$7.4B） |
| 新增 AI 云合同（季内） | $B | >30（不耗 ORCL 资本） |
| GPU 交付量（季内） | 万 | >30（较 Q4 近 3x） |
| AI 容量交付（MW） | MW | 850 |
| GPU 利用率 | % | 97.9% |

| 多云平台营收同比 | % | +353% |

**核心 4 季趋势（FY26 Q2→FY27 Q1）**

| 指标 | FY26Q2 (Nov'25) | FY26Q3 (Feb'26) | FY26Q4 (May'26) | FY27Q1 (Aug'26) |
|---|---|---|---|---|
| OCI 营收（$B） | 4.1 | 4.9 | 5.8 | 7.4 |
| OCI 营收同比 | +68% | +84% | +93% | +121% |
| RPO（$B） | 523.3 | 553 | 638 | 664 |

- ORCL 全为财务代理口径，与 GOOG/MSFT/AMZN 的「用户 / 调用量」不可直接比，仅 backlog/RPO 一项可弱对齐。

**跨家可比性注脚**（来自概念页）：**RPO（$664B）** 是「Cloud backlog / RPO」可比核心项，可直接对齐 AMZN AWS Backlog（$496B）、GOOG Cloud backlog（$514B）、MSFT cRPO（$678B）；ORCL 量级最大、但增速（+$209B YoY）与 GOOG/AMZN 三位数%不同口径（ORCL 为绝对额增量）。ORCL 不披露第一方模型 API 吞吐量，其 AI 势能靠「OCI 增速 + GPU 交付 + RPO」表征。

**小结**：ORCL 的 AI 势能呈现「RPO 暴增 + OCI 阶跃 + GPU 满负荷（97.9% 利用率）」特征，是五家 hyperscaler 中 capex 强度最高、FCF 压力最大的样本，且高度依赖 RPO 抵押式融资。

## 五、管理层重要谈话

**Safra Catz（CEO）/ Larry Ellison（CTO/董事长）**
- "Customer demand for AI Cloud Training and Inferencing Services continues to grow faster than supply… Oracle booked more than $30 billion of additional AI cloud contracts in Q1 increasing its RPO to $664 billion."（[来源: 8-K 引言]）
- 基于新合同结构，公司确认"对其融资计划**无增量影响**"（no incremental impact on its plans to raise capital）（[来源: 8-K]）。
- CFO Hilary Maxson：本季多数新增订单采用**预付款 / 客户提供硬件**模式，因此"不会给 Oracle 带来等比例的新增资本支出压力"（[来源: 证券时报转述, 2026-09-11]）。
- FY2027 资本投资计划：通过债务 + 股权组合融资约 **$40B**（含已完成的 $20B ATM 股权发行）；FY2026 已融资 $43B 债务 + $5B 股权（[来源: 8-K / onemoremoney]）。

**积极信号**：RPO $664B（+ $209B）、OCI +121%、Q1 史上首次环比正增长、预付款/BYO 模式降低资本压力。
**消极 / 需关注信号**：单季 capex $28.5B > 总营收 $19.3B、FCF −$5.4B；**S&P 将 ORCL 下调至 BBB-（距垃圾级仅一档）**；曾有最大数据中心园区 force majeure 通知（[来源: onemoremoney, 2026-09-30]）。

## 六、财务健康度

> 数据来源：ORCL 8-K（2026-09-10）现金流量表 / 资产负债表；信用评级来自公开报道。

| 指标 | 数值 | 备注 |
|---|---|---|
| OCF（季） | $23.0B | 同比 +184% |
| CapEx（季） | $28.5B | 同比 +235%（超总营收） |
| **OCF / CapEx** | **0.81x** | 现金流无法覆盖 capex |
| FCF（季） | **−$5.4B** | 去年同期 −$0.36B |
| 现金及等价物 | ~$36.4B | [来源: onemoremoney] |
| 应付票据与借款 | **~$125B** | [来源: onemoremoney] |
| 信用评级 | **BBB−（S&P，距垃圾级一档）** | [来源: onemoremoney, 2026-09] |
| 市值 | ~$417–440B | 较 52 周高点低 ~57% |

- **杠杆 / 流动性**：应付票据与借款 ~$125B、现金 ~$36B，净债务显著为正；S&P BBB− 反映市场对"举债建 AI"的担忧。
- **CapEx 周期定位**：OCF/CapEx **0.81x**、FCF 持续为负，是五家 hyperscaler 中**唯一 OCF/CapEx <1 且净债务高企**的 outlier（对比 MSFT 1.58x、AMZN 0.95x、GOOG 1.40x TTM、META 1.17x YTD）；"$664B RPO" 实质是已签约营收抵押，支撑持续举债。
- **资本配置取向**：以"预付款 / BYO 硬件"合同结构减少自身 capex 现金流出，同时大规模 ATM 股权发行 + 债务融资；管理层承诺 FY2028 FCF 转正（无具体季度）。

**小结**：ORCL 短中期财务韧性来自「RPO 抵押式融资能力 + 多云差异化定位」，但 **OCF/CapEx 0.81x、FCF 负、净债务 ~$90B+、BBB− 评级** 使其对 AI 基建回报兑现最敏感、约束力最强。
