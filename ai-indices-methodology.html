EAPI 企业 AI 渗透指数

EAPI（企业 AI 渗透指数）通过 npm 包下载量追踪企业在实际业务中引入 AI 工具的渗透速度。 本页说明其编制原理，并补充「真实支出指数」——引入 token 价格代理对下载量做平减， 剥离价格因素，逼近企业真实 AI 支出口径。

EAPI

Enterprise AI Penetration Index

EAPI 追踪企业在实际业务中引入 AI 工具的渗透速度，采用 npm 六包体系： AI SDK 三包（OpenAI/Anthropic/Google）代表模型调用层， 企业工具三包（dd-trace/snowflake-sdk/Atlassian Triggers）代表生产环境集成层。 几何加权综合两者，捕捉企业从"试用模型"到"深度集成"的完整渗透路径。

编制公式
# Step 1：归一化（各包除以基准周值，锚定 base=100）
norm[pkg, t] = downloads[pkg, t] / downloads[pkg, base] × 100

# Step 2：AI SDK 子指数（等权重几何均值）
AI_SDK_sub[t] = ( norm[openai,  t]
               × norm[anthropic, t]
               × norm[google,    t] )^(1/3)

# Step 3：企业工具子指数（等权重几何均值）
Enterprise_sub[t] = ( norm[dd-trace,              t]
                    × norm[snowflake-sdk,          t]
                    × norm[@atlaskit/rovo-triggers, t] )^(1/3)

# Step 4：综合指数（几何加权幂次组合）
EAPI[t] = AI_SDK_sub[t]^0.6  ×  Enterprise_sub[t]^0.4

# 采用几何均值而非算术均值：
#  — 几何均值对归一化比值做乘法等效于等比中项，对极端值有天然均值回归效应
#  — 避免被某一个包暴涨拉高综合指数失真

真实支出指数（价格平减）

EAPI 综合指数只反映下载量（用量）的增速。由于 token 价格指数持续下行， 仅看下载量会高估企业的"实际开支"。真实支出指数引入价格代理 OPTI_VERCEL_OUTPUT （Vercel token 价格指数，日线，2026-07-10 起）对 EAPI 做平减，剥离价格因素， 得到更接近企业真实支出的口径。

编制公式
# Step 1：每周价格比（周窗口 (t-7, t] 内日线均值 / 07-10 锚点）
price_ratio[t] = mean(OPTI_VERCEL_OUTPUT within week) / OPTI_VERCEL_OUTPUT(2026-07-10)

# Step 2：阻尼平减因子（α 为价格传导系数）
#  α=1.0 完全传导（硬平减，会夸大价格崩盘）
#  α=0.3 弱传导（企业锁价，现货跌几乎不传到实际支出）→ 当前取值
#  α=0.0 无传导（真实支出 == 名义 EAPI）
price_deflator[t] = price_ratio[t]^α        (α = 0.3)

# Step 3：真实支出指数 = 名义 EAPI × 阻尼平减因子
RealSpend[t] = EAPI[t] × price_deflator[t]

# Step 4：4 周移动平均（平滑周度噪声）
RealSpend_MA4[t] = mean(RealSpend[t], RealSpend[t-1], RealSpend[t-2], RealSpend[t-3])

# Step 5：一阶导数（周环比差分，刻画支出动能与拐点）
RealSpend_MA4_deriv[t] = RealSpend_MA4[t] − RealSpend_MA4[t-1]

# 注：纯 log2 不改变结果(2^log2(r)=r，等价于 α=1)，"维持7月高位"的
#     杠杆是 α 而非 log2；α=0.3 时真实支出稳在 7 月高位(约 160–200)。

口径对比：名义 EAPI vs 真实支出指数

口径 2026-07-13 2026-09-14 期间变化
名义 EAPI（下载量 / 用量） 163.26 281.09 +72.2%
真实支出指数（α=0.3 平减） 159.19 197.05 +23.8%

真实支出指数 09-14 为 197.05，与 7 月高位区间（约 160–200）基本持平： 尽管名义下载量近乎翻倍，但 token 价格下行拉低了单位支出，企业真实 AI 支出并未同比例膨胀， 印证「支出维持 7 月高位」的判断。

⚠️ 口径说明：OPTI_VERCEL_OUTPUT 是 Vercel token 价格的代理指标，并非 EAPI 内 npm 包（ai-sdk / dd-trace / snowflake-sdk）的真实合约价，且日线波动较大 （07-10 的 9.228 → 09-16 的 2.336，跌约 75%）。 采用 α=0.3 弱传导是为了反映 "企业多为锁价/合约价、现货价格暴跌几乎不传导到实际支出"的现实；结论的 方向稳健，但绝对幅度为示意值。
